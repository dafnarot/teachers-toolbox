# ארגז כלים דיגיטליים חכמים למורים

מאגר כלים דיגיטליים וכלי AI למורים בישראל, עם דוגמאות מהכיתה ומידע על תנאי השימוש.
מאת דפנה רוט, "הוראה חכמה בעידן ה-AI".

## צפייה באתר במחשב

לוחצים לחיצה כפולה על הקובץ `index.html`.

## עדכון התוכן

כל התוכן נמצא בקובץ `data/tools.js`. הסבר מלא נמצא בקובץ `data/איך-לעדכן-את-המאגר.md`.
