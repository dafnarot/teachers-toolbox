# איך לעדכן את מאגר הכלים

כל התוכן של האתר נמצא בקובץ אחד: `tools.js`. האתר קורא את הקובץ הזה, ולכן כשמעדכנים אותו אין צורך לגעת בקוד.

## הוספת הסבר קצר משלך

בכל כלי יש שדה בשם `note`. הוא ריק כרגע, וכל עוד הוא ריק לא מוצג כלום. כדי להוסיף הסבר, כותבים אותו בין המירכאות:

```json
"note": "הכלי שאני הכי ממליצה עליו להכנת חידון מהיר בתחילת שיעור."
```

ההסבר יופיע בראש חלון הפרטים של הכלי, בתיבה מודגשת.

## עדכון הקישורים לקבוצות שלך

בראש הקובץ `tools.js`, בתוך `meta`, יש שני שדות:
- `myGroups`: רשימת הקבוצות שמוצגות באזור "נעים להכיר". לכל קבוצה כותבים `name` (שם הקבוצה), `type` (`whatsapp` או `facebook`) ו-`url` (קישור ההצטרפות).
- `allMyLinks`: הקישור לכפתור "כל הקישורים שלי" (כרגע כרטיס הביקור הדיגיטלי).

## הוספת כלי חדש

1. מעתיקים כלי קיים: מהסוגר `{` ועד הסוגר `}` שסוגר אותו, כולל הפסיק שאחריו.
2. מדביקים את ההעתק ומשנים את השדות:

| שדה | מה כותבים בו |
|---|---|
| `id` | מזהה באנגלית בלי רווחים, שאף כלי אחר לא משתמש בו (למשל `my-tool`) |
| `name` | שם הכלי |
| `url` | הקישור הרשמי |
| `isGoogle` | `true` לכלי Google, ו-`false` לכל כלי אחר |
| `description` | תיאור קצר |
| `capabilities` | רשימת היכולות המרכזיות |
| `categories` | הקטגוריות של הכלי. לכל קטגוריה כותבים `highlight` (מה הכלי עושה בקטגוריה הזו) ו-`example` (דוגמה פדגוגית) |
| `keywords` | מילות חיפוש בעברית |
| `access` | תנאי השימוש. בכלי Google יש גם `personalAccount` (חשבון אישי) ו-`educationAccount` (חשבון חינוכי) |
| `verifiedOn` | תאריך הבדיקה בפורמט `2026-11-22`, או `null` אם המידע עוד לא נבדק |
| `sources` | קישורים למקורות שבהם נבדק המידע |
| `note` | הסבר קצר משלך (אפשר להשאיר ריק: `""`) |

לכל קטגוריה ברשימת `categories` יש גם צבעים ואייקון:
- `color`: צבע ההדגשה.
- `tint`: הגוון הבהיר של אותו צבע.
- `ink`: צבע הטקסט הכהה.
- `icon`: שם האייקון מתוך tabler.io/icons, עם התחילית `ti-`.

הקטגוריות האפשריות הן:

| מזהה | שם באתר |
|---|---|
| `ai-assistants` | עוזרי AI ומחקר |
| `presentations` | יצירת מצגות |
| `images` | תמונות ואינפוגרפיקות |
| `videos` | וידאו ושמע |
| `quizzes` | חידונים ומשחקים |
| `worksheets` | דפי עבודה ותכנון הוראה |
| `spaces` | מרחבי למידה ושיתוף |
| `building` | בניית אתרים ואפליקציות |

## צפייה באתר במחשב

פותחים את התיקייה `teachers-toolbox` ולוחצים לחיצה כפולה על הקובץ `index.html`. האתר ייפתח בדפדפן.

אחרי עריכה של `tools.js` שומרים את הקובץ ומרעננים את הדף בדפדפן (F5).

כדי לערוך את `tools.js`: לחיצה ימנית על הקובץ ← "פתח באמצעות" ← פנקס רשימות (Notepad).

## כללים שכדאי להקפיד עליהם

- כל טקסט נכתב בין מירכאות כפולות `"..."`.
- בין פריטים ברשימה שמים פסיק, אבל אחרי הפריט האחרון לא שמים פסיק.
- אם צריך מירכאות בתוך הטקסט, כותבים לפניהן לוכסן: `\"`.
- לא משנים את השורה `window.TOOLS_DATA = {` שבראש הקובץ ואת הנקודה-פסיק `;` שבסופו.
- אם אחרי השמירה מופיעה באתר הודעה שלא ניתן לטעון את המאגר, כנראה שחסר פסיק או מירכאה. כדי למצוא את הטעות, מעתיקים לאתר jsonlint.com את כל מה שבין הסוגר `{` הראשון לסוגר `}` האחרון.
